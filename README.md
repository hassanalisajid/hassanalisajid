# 💫 About Me:
I'm an AI/ML engineer with a BS in Artificial Intelligence from COMSATS University Islamabad, working as a Junior Machine Learning Engineer at Launchify LLC, where I build and deploy production models on AWS that stay accurate while using less compute. I co-built Pixie the Robot, an emotionally intelligent, voice- and gesture-controlled assistant that won Overall Winner at the COMSATS Industrial Connect Expo 2025. My work centers on computer vision, emotion and gesture recognition, and LLM applications such as RAG. I'm currently exploring LLM agents and computational intelligence, and I'm open to research collaboration in AI/ML. Ask me about computer vision, RAG, or taking ML models from notebook to cloud. 📩 hassanalisajid786@gmail.com
